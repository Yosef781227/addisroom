# AddisRoom design reference

Adapted from Villa Agency v1.0.0 by TemplateMo, supplied by the user as
`VillaAgency-v1.0.0.zip` and distributed by ThemeWagon.

- Original: https://templatemo.com/tm-591-villa-agency
- Demo: https://templatemo.com/templates/templatemo_591_villa_agency/
- Distribution: https://themewagon.com/themes/villa-agency/

The author permits commercial and noncommercial template adaptation. Source attribution is retained in this document; the visible template credit
was removed at the site owner’s request. Poppins, orange (#f35525), charcoal (#1e1e1e), white,
photographic banners, rounded dark buttons, property cards and section rhythms
follow this reference. The user-supplied archive was inspected as reference data.

`public/images/villa` contains original demo architecture photographs used only
as decorative hero / page / account imagery. They do not represent actual AddisRoom
listings or assert that the pictured buildings are in Ethiopia. Replace these
brand photographs with commissioned Addis Ababa imagery when available. Property
cards and maps continue to use actual database records and their own photos.

All UI is implemented in React/Next.js; no Bootstrap, jQuery, counters, fake
awards, demo addresses, tracking scripts, or template contact endpoints are loaded.
Rental search, identity review, admin, payments, messages, saved listings and
location data remain backed by AddisRoom's existing implementations.
